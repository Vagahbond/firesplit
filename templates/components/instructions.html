Comment obtenir votre token :

  1. Connectez-vous à Fierfly-III (money.vagahbond.com)
  2. Allez dans Options > Profile > OAuth
  3. Générez un nouveau token sous "Personal access tokens"
  4. Ne cliquez qu'une fois, le token va mettre du temps à apparaître et c'est normal!
  5. Copiez le token ci-dessous
  6. Gardez le token quelque part (ex: pass.vagahbond.com). Cette page vous le re-demandera !
